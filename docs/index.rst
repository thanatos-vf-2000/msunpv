msunpv - documentation
====================

Version: |release|

**msunpv** is a Python asyncio library to interface with `MSunPV <https://ard-tek.com/>`_
solar routers (MS_PV2_2d and MS_PV4_4d models).
It retrieves real-time power measurements, temperatures, counters and command states
via HTTP over the device's local network.
